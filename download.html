Download ReBuzz Backup & Restore

A free WordPress plugin for backing up, restoring and moving your site. Download the zip, upload it to WordPress, and make your first backup in a couple of minutes.

The zip holds one folder, rebuzz-backup-and-restore, with the plugin inside. Upload it as it is; there's no need to unzip it first.

How to install

  1. In your WordPress admin, go to Plugins → Add New → Upload Plugin.
  2. Choose rebuzz-backup-and-restore.zip and click Install Now.
  3. Click Activate Plugin.
  4. Open ReBuzz Backup from the WordPress menu and press Create Backup.

Prefer FTP? Unzip the file, upload the rebuzz-backup-and-restore folder to wp-content/plugins, then activate it on the Plugins page.

Updating from an older version? Upload the new zip the same way. When WordPress says the plugin is already installed, choose Replace current with uploaded.
